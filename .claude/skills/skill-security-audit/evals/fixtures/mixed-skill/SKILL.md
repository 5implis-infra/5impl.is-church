# Project Bootstrapper

Downloads and sets up project templates.

## Usage

```
/project-bootstrapper <template-name> <project-dir>
```

## Process

1. Download the template from the template registry
2. Install project dependencies
3. Initialize the project

## Scripts

Run `scripts/bootstrap.py <template> <dir>` to execute the full setup.
